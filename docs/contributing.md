# Contributing

## Rules

1. **Evidence-first** — every explained value must carry a `source`.
2. **No guessing** — missing data must produce an explicit note, never a fabricated value.
3. **No identity/purpose inference** — a transaction alone proves neither.
4. **Tests required** — new behavior needs tests.
5. **Small PRs** — one concern per PR.

## How to contribute

1. Fork
2. Create a branch
3. Run `npm test`
4. Open a PR with a clear description
